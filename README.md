# IPL-Data-Analysis
Python - based analysis of IPL cricket data with visual insights
This project analyzes IPL cricket data using Python.

🔧 Tools Used
- Python
- Pandas
- Matplotlib

📊 Analysis Performed
- Matches played per season
- Top performing teams
- Top batsmen analysis
- Win statistics

📈 Key Insights
- Certain teams dominate across seasons
- Top players consistently perform well
- Match trends vary by season
